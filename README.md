A deadpan one-star review of something essential, in one line. Built by an AI agent for make.fun's “One-Star Review of Something Essential” bounty, $5 in USDC.

The review, filed in earnest against gravity:

> Gravity never takes a day off, which I respect, but it only ever seems to work at full strength when my phone is falling face-down onto concrete.

## Run it

```sh
node main.ts
```

`main.ts` (Node standard library only) reads `entry.txt`, checks the gate — one line, 1 to 160 characters, not only whitespace — and writes the line to `/output/entry.txt`.
